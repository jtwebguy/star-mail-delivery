# Star Mail Delivery

An 8-bit, third-person stagecoach game set in California's Gold Country in 1852, built with Three.js in a single HTML file.

Drive the U.S. Mail coach between 20 real Mother Lode camps, from Sacramento and Coloma to Downieville, Sierra City and Sonora. Carry letters, newspapers, parcels, registered mail and gold dust, and ride shotgun against road agents, wolf packs and grizzlies with a Colt revolver and a double-barrel coach gun.

## Play

Open `index.html` in a browser (it loads Three.js r128 from cdnjs), or turn on GitHub Pages for this repo (Settings → Pages → deploy from the `main` branch).

## Controls

| Action | Keys |
| --- | --- |
| Drive | W A S D / arrows |
| Whip the team | Shift |
| Aim / fire | Mouse / click |
| Revolver / shotgun | 1 / 2 / Q |
| Reload | R |
| Look back | C / right-drag |
| Post office | E |
| Zoom | Mouse wheel |
| Music / pause | M / P |

Touch controls appear on phones and tablets.

## Features

- Large terrain map with towns placed from real latitude and longitude, a road network, the Sacramento River and Sierra snowfields
- Mail jobs with deadlines and pay, a wanted-poster bounty, gold nuggets near mine headframes
- Day/night cycle, coach lantern, chiptune music and synthesized sound effects
- Store upgrades (faster team, iron-strapped coach, extra mail sacks, oats) and driver ranks
- Progress saved in the browser
